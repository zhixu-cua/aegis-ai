# 实施计划与里程碑（独立系统 + 菜单跳转接入）

## 1. 目标与约束

### 1.1 目标

- 交付一个独立部署的售后助手系统
- 网站群侧仅增加一个菜单入口跳转
- MVP 聚焦“知识库问答 + 引用来源 + 审计”，不做工单闭环

### 1.2 约束

- 个人可完成，优先可部署、可运维、可回滚
- 知识库全站通用
- 首期允许独立登录

## 2. 工作分解（按阶段）

## 2.1 阶段 0：准备与基线

产出物：

- 文档确认：需求、架构、接口对接
- 开发环境：Windows 本地开发机，能运行 Docker Desktop
- 目录规划：前端、Spring Boot、FastAPI、部署脚本、SQL
- 环境约定：本地开发按 Windows，目标部署按 Linux 容器环境设计

验收点：

- 可在本地一键拉起基础依赖（Postgres/Redis/MinIO/Ollama）
- 不依赖 Windows 绝对路径即可完成后续迁移

## 2.2 阶段 1：独立系统门户与鉴权

目标：

- 形成可登录、可访问的独立门户
- 为后续问答和管理能力提供页面承载

任务清单：

- 助手系统前端页面骨架（登录/问答/知识库/审计菜单）
- Spring Boot 提供登录与用户信息接口
- 用户与角色模型（至少：普通用户、管理员）
- 基础审计：登录、退出、访问记录

验收点：

- 能登录进入系统
- 能看到问答页面与管理页面入口

## 2.3 阶段 2：问答链路打通（无知识库也能回答）

目标：

- 先打通从门户到模型的最短链路
- 确保可观测与可降级

任务清单：

- Spring Boot 问答 API：`POST /api/assistant/chat`
- FastAPI 生成接口：调用 Ollama 完成基础回答
- 基础超时与重试策略
- 问答日志落库（至少：用户、问题、回答摘要、耗时）
- 前端问答 UI：输入、展示、复制回复

验收点：

- 页面可发起提问并获得回答
- 失败时有清晰提示
- 问答日志可查询到记录

## 2.4 阶段 3：知识库入库与检索增强（RAG）

目标：

- 支持文档上传、解析、切分、向量化、检索召回
- 回答必须带引用来源

任务清单：

- 文档上传接口与 MinIO 存储
- 文档状态机：待处理/处理中/成功/失败
- 文档解析与切分策略
- 向量化与写入 pgvector
- 检索 TopK 与 Prompt 拼装
- 回答结构化输出：结论/步骤/引用/建议人工
- 引用来源展示：文档名、片段摘要

验收点：

- 上传文档后可看到入库状态
- 问答会命中知识库，并返回引用来源
- 无命中时能明确拒答或提示转人工

## 2.5 阶段 4：知识库管理与运维能力

目标：

- 管理员可维护知识库和查看质量数据

任务清单：

- 文档列表、删除、重建索引
- 入库失败原因展示与重试
- 审计页面：按用户、时间、关键词筛选
- 基础统计：命中率、拒答率、平均耗时

验收点：

- 知识库管理闭环可用
- 能追溯每次回答引用了哪些资料

## 2.6 阶段 5：网站群菜单接入与发布策略

目标：

- 网站群只新增菜单跳转
- 助手系统可独立发布、独立回滚

任务清单：

- 确定助手系统访问地址与网络可达性
- 准备 Linux 服务器运行环境（Docker Engine、Compose、目录权限）
- 网站群新增菜单项并配置权限
- 回滚预案：菜单禁用/入口隐藏

验收点：

- 网站群后台可一键进入助手系统
- 禁用菜单即可完成回滚

## 3. 里程碑

- M1：独立系统可登录
- M2：问答链路打通（无知识库）
- M3：知识库上传入库完成
- M4：RAG 问答带引用来源
- M5：管理与审计能力可用
- M6：网站群菜单跳转接入完成

## 4. 风险清单与应对

- 模型效果不稳定
  - 应对：固定回答结构；引用机制；无命中即拒答
- 文档解析质量差
  - 应对：优先支持结构稳定格式；入库失败可重试；保留人工补充文档机制
- 单机资源不足导致响应慢
  - 应对：限制并发；缓存热点问答；后续替换 vLLM
- 账号体系割裂
  - 应对：首期独立登录；预留 SSO/票据透传接口
- 运维复杂度上升
  - 应对：组件最少化；统一 docker-compose；日志结构化
- Windows 与 Linux 环境差异导致路径或脚本问题
  - 应对：统一使用容器内 Linux 运行环境；对象存储 key 替代本地绝对路径；脚本分 PowerShell 与 Bash 两套说明

## 5. 回滚与降级策略

- 回滚（网站群侧）：禁用菜单入口
- 回滚（助手侧）：回退镜像版本或停止服务
- 降级（模型侧）：模型不可用时返回固定提示并记录告警
- 降级（检索侧）：检索不可用时拒答并建议人工处理

## 6. 验收用例建议

- 上传文档后，状态从“处理中”变为“成功”
- 同一个问题在有知识与无知识情况下，回答分别体现“引用来源/拒答”
- 删除文档后，相关问题不再命中该文档引用
- 审计页能按用户查询到问答记录，并查看引用来源
- 网站群菜单可跳转进入助手系统，禁用菜单后入口消失
