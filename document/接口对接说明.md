# 接口对接说明（网站群菜单跳转接入）

## 1. 目标与范围

本文档用于说明网站群与“售后助手独立系统”的对接方式，包含：

- 网站群侧最小改造点
- 菜单跳转接入方式
- 鉴权与安全建议
- 助手系统对外接口清单（面向前端/管理端）
- 与 AI 服务的内部接口边界

本期对接原则：

- 网站群仅提供菜单入口，跳转到助手系统
- 首期允许独立登录，后续可扩展单点登录或票据透传
- 网站群不直连 AI 服务

## 2. 系统与网络边界

### 2.1 组件边界

- 网站群主系统
  - 仅增加一个菜单入口链接
  - 不承载模型调用、知识库、向量检索能力
- 售后助手独立系统
  - 独立域名/子域名或独立端口
  - 提供门户页面、知识库管理、问答、日志审计
  - 对内调用 FastAPI AI 服务

### 2.2 网络建议

- `assistant-web` 与 `web-backend` 对外暴露（内网或受控公网均可）
- `ai-service` 仅内网可访问
- 数据库、Redis、MinIO 仅内网可访问
- 本地开发可在 Windows 使用 Docker Desktop；正式部署建议在 Linux 服务器运行容器

## 3. 网站群侧改造（最小集成）

### 3.1 菜单入口

网站群后台新增菜单项：

- 菜单名称：售后助手
- 访问地址：`https://assistant.example.com/`（示例）
- 打开方式：新标签页或同页跳转均可

### 3.2 退出与回滚

网站群侧的回滚成本应为：

- 移除菜单项或禁用菜单权限即可

## 4. 登录与鉴权方案

### 4.1 首期推荐（独立登录）

助手系统提供独立账号体系或仅管理员创建账号，特点：

- 网站群接入改动最少
- 便于先上线验证价值

安全建议：

- 助手系统仅对内网开放，或加访问白名单
- 启用访问频率限制与基础审计

### 4.2 后续可选（SSO/票据透传）

当需要体验一致和统一权限时，可扩展：

- 网站群跳转携带一次性票据（短时有效）
- 助手系统通过回调接口向网站群验证票据并获取用户信息

票据建议特性：

- 有效期短（例如 60 秒）
- 一次性使用
- 绑定来源 IP 或 UA（可选）

## 5. 助手系统外部接口清单（Spring Boot）

说明：

- 以下接口为助手系统的门户与管理功能 API
- 前端门户与管理台都应通过这些接口访问
- 接口路径仅为建议，可按你们现有网关规范调整

### 5.1 基础与鉴权

- `POST /api/auth/login`
  - 入参：`username`、`password`
  - 出参：`token`、`expiresIn`、`user`
- `POST /api/auth/logout`
- `GET /api/auth/me`

### 5.2 会话管理

- `GET /api/assistant/sessions`
  - 出参：会话列表
- `POST /api/assistant/sessions`
  - 入参：`title`（可选）
  - 出参：`sessionId`
- `GET /api/assistant/sessions/{id}/messages`
  - 出参：消息列表

### 5.3 问答接口

- `POST /api/assistant/chat`
  - 入参：
    - `sessionId`（可为空，空则自动新建）
    - `question`
  - 出参：
    - `answer`
    - `references`（引用列表）
    - `needManual`（是否建议人工处理）
    - `hitCount`
    - `costMs`

引用 `references` 建议字段：

- `documentId`
- `documentName`
- `chunkId`
- `snippet`

### 5.4 知识库管理

- `POST /api/knowledge/upload`
  - 说明：上传文件并创建入库任务
  - 入参：`multipart/form-data`，字段 `file`
  - 出参：`documentId`
- `GET /api/knowledge/documents`
  - 出参：文档列表与状态
- `DELETE /api/knowledge/documents/{id}`
  - 说明：删除文档并同步删除切片与向量
- `POST /api/knowledge/documents/{id}/reindex`
  - 说明：重建索引（重新解析与向量化）

### 5.5 运维与审计

- `GET /api/audit/assistant-logs`
  - 说明：按时间、用户筛选问答记录
- `GET /api/audit/knowledge-ops`
  - 说明：上传、删除、重建等操作日志

### 5.6 接入配置（后续）

仅当你决定做 SSO/票据透传时需要：

- `GET /api/integration/portal-config`
- `POST /api/integration/portal-config`

可配置项建议：

- 网站群系统标识
- 回调验证地址
- 票据签名密钥或公钥
- 允许来源域名列表

## 6. 助手系统内部接口（Spring Boot -> FastAPI）

说明：

- 仅内部调用，不对外开放
- 应部署在内网网络段或通过 service mesh / 内网防火墙限制

### 6.1 问答内部接口

- `POST /internal/rag/query`
  - 入参：
    - `question`
    - `sessionId`
    - `userId`
  - 出参：
    - `answer`
    - `references`
    - `needManual`
    - `hitCount`
    - `costMs`

### 6.2 文档入库内部接口

- `POST /internal/kb/ingest`
  - 入参：
    - `documentId`
    - `bucket`
    - `objectKey`
    - `fileType`
  - 出参：
    - `status`
    - `message`

说明：

- 不建议在接口中传递 Windows 或 Linux 本机绝对路径
- 建议统一通过 MinIO 对象存储的 `bucket + objectKey` 定位文件，避免跨系统部署时路径不兼容

### 6.3 文档删除内部接口

- `POST /internal/kb/delete`
  - 入参：
    - `documentId`
  - 出参：
    - `status`
    - `message`

## 7. 前端接入建议（独立系统）

### 7.1 门户页面结构

- 登录页
- 问答页
  - 左侧会话列表
  - 右侧问答区
  - 引用来源区
- 知识库管理页
  - 文档上传
  - 文档列表与状态
  - 删除与重建
- 审计页（管理员）

### 7.2 错误处理

- 模型不可用：提示“系统繁忙，请稍后重试”
- 检索无命中：提示“未找到依据，建议人工处理或补充信息”
- 入库失败：展示失败原因并支持重试

## 8. 安全基线

- 上传文件白名单：`pdf/doc/docx/md/html/txt`
- 上传大小限制：建议 20MB 或按环境调整
- 请求限流：按用户与 IP 维度限制
- 审计落库：保留最少可追溯字段，敏感信息可做摘要存储
- 防提示注入：系统提示固定；引用片段进入 Prompt 前做清洗
